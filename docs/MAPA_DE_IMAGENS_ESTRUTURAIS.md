## Produtos

Pasta: `/assets/products/`

Cada produto segue o padrão:

```text
/assets/products/[slug-do-produto]/principal.jpg
/assets/products/[slug-do-produto]/galeria-01.jpg
/assets/products/[slug-do-produto]/galeria-02.jpg
/assets/products/[slug-do-produto]/galeria-03.jpg
```

Exemplo:

```text
/assets/products/mucha/principal.jpg
/assets/products/linha-chilena/principal.jpg
```

## Regra de cuidado

Não substitua a pasta `assets` inteira sem conferir os arquivos internos.
O ideal é enviar/mesclar os arquivos mantendo esta estrutura.
